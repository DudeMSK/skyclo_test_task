# Отчёт по оплатам работ подрядчиков

CLI-программа строит бухгалтерский отчёт по договорам, работам и платежам на
выбранную дату. Она показывает:

- по каждой работе — цену, выплаченную сумму и остаток к оплате;
- по каждому договору — исходную сумму, стоимость действующих и отменённых
  работ, общую выплату и остаток.

Программа читает исходные CSV-файлы из каталога `data/` и создаёт два отчёта,
которые можно открыть в Excel или другом табличном редакторе.

## Требования

- Python 3.11 или новее;
- сторонние библиотеки не требуются.

Денежные суммы рассчитываются через `Decimal`, без использования `float`.

## Быстрый запуск

Из корня проекта выполните:

```bash
python3 report.py --date 2026-11-10
```

Команда прочитает данные из `data/` и создаст каталог `report/` с файлами:

- `report/works_report.csv` — детализация по работам;
- `report/contracts_report.csv` — итоги по договорам.

Для контрольной даты `2026-11-10` итоги должны быть следующими:

| Договор | Выплачено | Осталось оплатить |
|---|---:|---:|
| D-1 | 315 000,00 ₽ | 185 000,00 ₽ |
| D-2 | 75 000,00 ₽ | 15 000,00 ₽ |

## Параметры CLI

```text
python3 report.py --date YYYY-MM-DD [--data-dir PATH] [--output-dir PATH]
```

- `--date` — дата, на которую строится отчёт; обязательный параметр;
- `--data-dir` — каталог с входными CSV, по умолчанию `data`;
- `--output-dir` — каталог для результата, по умолчанию `report`.

Пример с явным указанием каталогов:

```bash
python3 report.py \
  --date 2026-11-10 \
  --data-dir data \
  --output-dir report
```

Полную справку можно вывести командой:

```bash
python3 report.py --help
```

## Входные данные

Каталог `data/` должен содержать:

- `contracts.csv` — договоры;
- `works.csv` — работы по договорам;
- `payments.csv` — платежи;
- `FORMAT.md` — описание колонок и допустимых статусов.

Некорректная дата, сумма, статус или ссылка на неизвестный договор либо работу
завершает программу с понятным сообщением об ошибке.

## Проверка решения

Запустить автоматические тесты:

```bash
python3 -m unittest discover -s tests -v
```

Ожидаемый результат: пять тестов завершаются со статусом `OK`. Тесты проверяют
контрольный отчёт на `2026-11-10`, исторические статусы работ и платежей,
возвраты, точность денежных значений и равенство распределённых выплат итогу
договора.

После тестов можно заново построить контрольный отчёт:

```bash
python3 report.py --date 2026-11-10
```

## Основные правила расчёта

- учитываются только деньги, фактически выплаченные к выбранной дате;
- платежи в очереди не считаются выплаченными;
- возвращённый платёж перестаёт учитываться с даты возврата;
- отменённая на дату отчёта работа не образует задолженность;
- привязанные платежи сначала относятся к указанным работам;
- непривязанные выплаты закрывают сначала принятые, затем плановые работы.

Полное описание допущений и альтернатив находится в `DECISIONS.md`.

## Документация проекта

- `DECISIONS.md` — принятые решения и влияние допущений на отчёт;
- `ACCOUNTANT_NOTE.md` — краткая записка бухгалтеру;
- `CODEX.md` — правила разработки и проверки изменений;
- `CHANGELOG.md` — история изменений;
- `codex-transcript.md` — транскрипт рабочей сессии.
